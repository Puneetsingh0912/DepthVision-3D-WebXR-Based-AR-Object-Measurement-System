This prototype calculates single-point distance and exposes depth metadata. Reliable full object dimensions need object segmentation and a calibrated multi-frame point-cloud fusion pipeline; it does not claim to reconstruct a complete 3D box automatically yet.

Privacy: depth and pose are processed in this page; no server upload is implemented. Exported CSV is downloaded locally. Browser/device support and depth quality vary.
